2. 신뢰도 분석 (크론바흐 α)

분석 → 척도 → 신뢰도 분석

분석 → 척도 → 신뢰도 분석 · 모형: 알파
  1. 변수 하나의 문항들을 오른쪽 항목 칸으로 옮김 (예: 혁신행동1~6)

  3. 결과 표에서 크론바흐 알파 값을 확인 (기준 0.6 이상)
  4. 변수마다 따로 반복
