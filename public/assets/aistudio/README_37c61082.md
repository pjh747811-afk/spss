# 통계방법 실습 웹앱 (SPSS 순서 재현)

2026.11.21 수업 노트와 `매개효과test.sav` 데이터를 기반으로 만든 **브라우저용 통계 실습 앱**입니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 메인 웹앱 (브라우저에서 바로 열기) |
| `data.json` / `data_items.csv` | 내장 설문 데이터 |
| `analyze.py` | Python으로 동일 분석을 다시 실행하는 스크립트 |

## 사용 방법

### 1. 웹앱 (추천)

1. `index.html`을 더블클릭하거나 브라우저로 엽니다.
2. 왼쪽 메뉴에서 단계별로 진행합니다.
   - 0. 개요 & 데이터
   - 1. 요인분석 (타당성)
   - 2. 신뢰도 분석 (Cronbach α)
   - 3. 변수 계산 (합변수)
   - 4. 상관분석
   - 5. 회귀분석 (H1·H2·H3)
   - 6. 결과 요약 & 제출

각 단계에 **SPSS 메뉴 경로**, **실제 계산 결과**, **해석**이 함께 표시됩니다.

### 2. Python 스크립트

```bash
pip install pyreadstat pandas numpy scipy statsmodels
python analyze.py /path/to/매개효과test.sav
```

## 분석 결과 요약 (데이터 기준)

| 가설 | 수정 R² | 결과 |
|------|---------|------|
| H1 (심리자본 ← 리더십 4차원) | .378 | 카리스마·배려·지적자극 유의, 동기부여 비유의 |
| H2 (혁신행동 ← 심리자본) | .131 | 유의 |
| H3 (혁신행동 ← 리더십 4차원) | .258 | 카리스마만 유의 |

## 참고

- 요인분석의 상세 회전 행렬은 SPSS에서 확인하는 것을 권장합니다.
- 웹앱은 수업 노트와 동일한 수치를 재현하도록 사전 계산된 결과를 사용합니다.
- 다른 데이터로 분석하려면 `analyze.py`를 수정하거나 SPSS/jamovi/R 등을 사용하세요.
