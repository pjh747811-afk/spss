# 통계방법 실습 웹앱 (데이터 업로드형)

CSV를 올리면 **신뢰도(α) → 합변수 → 상관 → 회귀(H1·H2·H3)** 를 자동으로 계산합니다.

## 사용 방법

1. `spss_webapp.zip` 압축 해제
2. `index.html` 더블클릭  
   (샘플 데이터 버튼이 안 되면 같은 폴더에서 `python -m http.server 8080` 후 http://localhost:8080)
3. **CSV 업로드** 또는 **수업 샘플 데이터 불러오기**
4. **변수 매핑**에서 문항 체크 + 가설(매개/종속/독립) 설정
5. **분석 실행**
6. 결과 확인 후 CSV 다운로드

## 파일

| 파일 | 설명 |
|------|------|
| index.html | 웹앱 (메인) |
| data_items.csv | 수업 샘플 데이터 |
| analyze.py | Python 재현 스크립트 (선택) |

## CSV 형식

- 첫 행: 변수명 (예: 혁신행동1, 카리스마1 …)
- 이후 행: 숫자 점수
- SPSS: 파일 → 다른 이름으로 저장 → CSV

## 분석 내용

- Cronbach’s α (구성개념별)
- 합변수 = 문항 평균
- Pearson 상관 (하삼각)
- 다중회귀 H1 / H2 / H3 (수정 R², F, B, β, t, p)

※ 요인분석(타당성)은 SPSS/jamovi 사용을 권장합니다.  
※ p값은 브라우저 근사 계산입니다. 논문 제출 시 SPSS와 교차 확인하세요.
